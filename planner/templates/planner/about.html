About this project

Student Assignment Tracker is a Django web application built for INF601 – Advanced Programming in Python, Mini Project 6.

Each student has a private list of assignments. Every assignment records its course, due date, priority, and whether it is finished. Users can only see and manage their own work.

Features

  • A dashboard with progress, overdue work, and what's due this week
  • An assignment list you can filter by status
  • A form for adding assignments with due dates and priorities
  • Private data: each user's assignments are visible only to them
  • A customized Django admin site for managing all data

Built with

Python Django 5.2 SQLite Bootstrap 5
